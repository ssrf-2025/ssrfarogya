# Sivaraman Siddha Research Foundation

A responsive, single-page website for Sivaraman Siddha Research Foundation (SSRF), built as a dependency-free static site.

## Run locally

Open `index.html` in a browser. No package installation, build step, or development server is required.

The inquiry form validates the required fields and opens the visitor's default email application with a prefilled message to `arogyassrf@gmail.com`. It does not submit data to a server.

## Contents

The page includes the foundation overview, institutional pillars, six focus areas, published and ongoing research, conferences and scientific engagement, AURA 2027 registration, institutional collaborations, documented community activities, leadership, CSR and compliance information, registration document links, and contact details.

The registration PDFs and trustee portraits are stored alongside `index.html`. Keep these files together when moving or publishing the site.

AURA 2027 registration is embedded from Google Forms and also linked externally as a fallback. Google Forms may require sign-in depending on the form's access settings.
